# LumenDotfiles

A clean, modern Linux desktop built around **Material 3**, **Quickshell**, and **Niri**.

Lumen is designed to keep the desktop minimal, responsive, and cohesive without sacrificing functionality.

## ✦ Features

- Material 3-inspired design
- Quickshell desktop shell
- Niri Wayland compositor
- Dynamic theming
- Custom bars, widgets, and system controls
- Keyboard-driven workflow
- Minimal animations and visual clutter
- Designed for Wayland

## 🖥️ Stack

| Component | Software |
|-----------|----------|
| Compositor | Niri |
| Shell | Quickshell |
| Terminal | Kitty |
| Notifications | Quickshell |
| Launcher | Rofi |
| Bar | Quickshell |
| GTK Theme | WhiteSur-Dark |
| Cursor | WhiteSur |
| Font | JetBrains Mono Nerd Font |
